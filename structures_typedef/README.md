# C - Structures, typedef

This project covers structures and typedef in C.

## Files
- dog.h: defines struct dog, its dog_t alias, and the dog function prototypes
- 1-init_dog.c: initializes a struct dog variable
- 2-print_dog.c: prints a dog's information
- 4-new_dog.c: creates a dog with copies of its name and owner
- 5-free_dog.c: frees a dog and its allocated strings
